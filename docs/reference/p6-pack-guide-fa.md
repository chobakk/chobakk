# بسته مهارت‌های Primavera P6 برای Claude

این بسته برای استفاده بدون اتصال به Primavera P6، بدون MCP Server و بدون اتصال به دیتابیس تهیه شده است.

## محتویات
- ۱۵ مهارت اصلی برگرفته از مخزن `nizarhamza/p6-mcp-shop`
- فایل `SKILL.md` هر مهارت
- مستندات مرجع هر مهارت شامل نمونه گزارش، کنترل‌ها، فیلدها و مشخصات
- یک دستورالعمل فارسی برای استفاده آفلاین در Claude
- مجوز اصلی مخزن در فایل `LICENSE`

## نکته بسیار مهم درباره محدودیت‌ها
مهارت‌های اصلی این مخزن برای فراخوانی ابزارهای یک P6 MCP Server طراحی شده‌اند. چون قرار نیست MCP Server نصب یا متصل شود:
- Claude نمی‌تواند مستقیماً پروژه‌های داخل نرم‌افزار Primavera یا دیتابیس P6 را بخواند یا تغییر دهد.
- دستورهای داخلی مربوط به فراخوانی ابزارهای MCP به‌تنهایی اجراشدنی نیستند.
- با این حال، Claude می‌تواند از منطق، چک‌لیست‌ها، تعاریف، نمونه گزارش‌ها و قواعد این مهارت‌ها برای تحلیل فایل‌هایی که خودت در گفتگو بارگذاری می‌کنی استفاده کند؛ مانند XER، Excel، PDF و گزارش‌های برنامه زمان‌بندی.
- اگر فایل/داده لازم در دسترس نباشد، باید آن را درخواست کند و نباید عدد، تاریخ، درصد پیشرفت، مسیر بحرانی یا نتیجه ممیزی را حدس بزند.

## روش استفاده پیشنهادی در Claude.ai
۱. یک Project جدید در Claude بساز.
۲. فایل‌های این بسته را از حالت ZIP خارج کن.
۳. پوشه `skills` و فایل `CLAUDE_PROJECT_INSTRUCTIONS_FA.md` را در Project Knowledge بارگذاری کن. اگر Claude امکان بارگذاری پوشه را نداد، فایل‌های هر مهارت و پوشه `reference` مربوط به آن را به‌صورت فایل‌های جداگانه بارگذاری کن.
۴. متن فایل دستورالعمل را در Project Instructions نیز قرار بده.
۵. برای تحلیل یک پروژه، فایل‌های خروجی Primavera یا گزارش‌های مرتبط را در همان گفتگو بارگذاری کن.

## استفاده در Claude Code
ساختار پوشه `skills` به‌صورت مهارت‌های مستقل و تخت است؛ هر پوشه یک مهارت است و فایل `SKILL.md` دارد. پوشه `skills` را در مسیر مهارت‌های پروژه یا کاربر Claude Code قرار بده.
