# واژه‌نامه
- PMS: فایل پیشرفت اکسل (Progress Measurement System؛ تعبیر کاربر). «PMS پیمانکار» = فایل روزانه پیمانکار.
- CSM = Consortium. DR = Daily Report. ARUP = Abadan Refinery Upgrading Project. PPC = Planning & Project Control.
- Up to Last / Today / Up to Now = تا دیروز / امروز / تا الان (UTL / TODAY / UTN در Ehdas).
- W.V = Weight Value، W.F = Weight Factor (تعریف کاربر).
- FRJP/FRJE = Sekaf&Farjoud اصلی/اکسترا (E=Extra)؛ SOL1/SOL2 = Soleh اصلی/اکسترا؛ Ehds = احداث (Ehdas).
- Tag: شماره تجهیز/ساختمان (مثل TK-20316 A, V-6620, SS-40-01).
- F9 در P6 = محاسبه مجدد برنامه (Schedule). Baseline = خط مبنا. DCMA 14 = چک‌لیست کیفیت برنامه.
