# منابع پیشنهادی کنترل پروژه نفت و گاز

## منابع رسمی
1. **Oracle Primavera P6 — مستندات رسمی**
   https://docs.oracle.com/en/industries/construction-engineering/primavera-p6-professional/26/books.html
   برای یادگیری ابزار زمان‌بندی، Baseline، به‌روزرسانی، مسیر بحرانی و گزارش‌ها.

2. **PMI — Standards & Practice Guides**
   https://www.pmi.org/standards
   برای WBS، زمان‌بندی و اصول مدیریت پروژه. بعضی استانداردها پولی یا نیازمند عضویت هستند.

3. **PMI — Earned Value Management**
   https://www.pmi.org/standards/earned-value-management
   برای فهم سنجش عملکرد، PV/EV/AC و پیش‌بینی وضعیت پروژه.

4. **GAO Schedule Assessment Guide**
   https://www.gao.gov/products/gao-16-89g
   راهنمای عمومی رایگان برای ارزیابی کیفیت برنامه زمان‌بندی، روابط فعالیت‌ها، منطق شبکه و ریسک تأخیر.

5. **GAO Cost Estimating and Assessment Guide**
   https://www.gao.gov/products/gao-20-195g
   برای اصول برآورد هزینه و ارتباط ریسک زمان‌بندی با هزینه.

## روش استفاده
- ابتدا مفاهیم را با آموزش فارسی و مثال ساده یاد بگیر.
- بعد به مستندات رسمی مراجعه کن تا واژگان و رفتار نرم‌افزار را دقیق‌تر بشناسی.
- برای کار واقعی، قرارداد، رویه کنترل پروژه، روش مصوب اندازه‌گیری پیشرفت، برنامه مبنا و قالب‌های کارفرما/پیمانکار مرجع اصلی‌اند.
- از دانلودهای غیررسمی کتاب‌های دارای حق نشر پرهیز کن. برای یادگیری اولیه از صفحات رسمی، راهنماهای رایگان و مطالب آموزشی مجاز استفاده کن.
